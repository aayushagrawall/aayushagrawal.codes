## 📁 File Structure

```
aayushagrawal.codes/
├── index.html          # Home
├── projects.html       # Projects list
├── shortcuts.html      # iOS Shortcuts
├── favicon.svg
├── sitemap.xml         # Page list for search engines
├── robots.txt          # Points crawlers to the sitemap
├── ads.txt             # Google AdSense publisher record
├── CNAME               # Custom domain for GitHub Pages
└── assets/
    ├── css/style.css   # Design tokens + all components
    ├── js/main.js      # Theme, nav, scroll reveal
    └── docs/           # Resume PDF
```

## 🚀 Deploy

Served by **GitHub Pages** from the `main` branch. No build step, just plain HTML, CSS and JS.
Push to `main` and the site updates in a minute or two.

> ⚠️ Don't delete `CNAME` (it breaks the custom domain) or `ads.txt` (it breaks AdSense).

## ✏️ Adding a project

1. Add a row to the project list in `index.html` and in `projects.html`.
2. Update `<lastmod>` for both pages in `sitemap.xml`.
3. Push to `main`.

## 🎨 Design

Minimal and typographic, with one orange accent. Light and dark themes follow the system setting and can be toggled manually.
Fonts: Geist, Geist Mono and Instrument Serif.
